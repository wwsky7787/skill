# dip-advisor

DIP 入组推荐技能：根据病人基础情况推荐分值最高的 DIP 入组方案，并支持 ICD-10 诊断编码查询。完全本地运行，无外网依赖。

## 数据与脚本

- `data/diagnoses.json`：ICD-10 诊断库，35,723 条 `[[编码, 名称], ...]`
- `data/core.json`：核心病组目录，按诊断编码前 4 位索引，2,378 键 / 5,669 条。病种编码格式为 `诊断编码-操作编码`，操作可多个（`/` 或 `+` 连接）；分值即 DIP 分值。
- `data/comp.json`：综合病组目录，按诊断类目索引，918 键 / 2,417 条。治疗方式为枚举代号（BSZL 保守治疗、ZDXCZ 诊断性操作、ZLXCZ-I 治疗性操作-I级、SS-I/SS-III 相关手术-I/III级等），不含具体手术编码。
- `data/operations.json`：DIP 相关操作库，1,511 条 `{操作编码: 操作名称}`（从核心病组反向抽取，仅服务本技能推荐）。
- `scripts/search.py`：统一查询脚本（Python，零第三方依赖）。

**付费标准系数（唯一改动点在 search.py 顶部常量）：** 职工 = 分值 × 5.69，居民 = 分值 × 4.36。输出所有费用时必须注明"按系数 5.69 / 4.36 计算"。

## 脚本用法

```bash
python scripts/search.py diag <关键词>       # 诊断查询，Top 5：编码 名称（支持名称子串或编码前缀）
python scripts/search.py group <诊断编码>    # 该诊断可入的全部病组（核心/综合/兜底），按分值降序，含费用
python scripts/search.py family <编码前3位>  # 该类目下所有核心病组键及最高分（诊断调整建议用）
```

## 判断用户意图

1. **DIP 入组推荐**（核心功能）：用户提供了病历、或描述了病人的诊断/操作、或要求推荐入组方案、分组调整、对比分值——走下面的"入组推荐工作流"。
2. **纯 ICD 查询**：用户只问某个诊断/疾病对应的编码，或给编码问名称——调 `diag`，直接输出 Top 5（`编码 名称`），一行一条，不做分组推荐。

## 入组推荐工作流

### 第 1 步：提取诊断与操作

从输入（自由文本病历 / 结构化描述 / 任意形态）中提取：
- 所有明确诊断（主诊断、次要诊断、其他诊断）
- 已做或计划中的操作

不确定诊断名称时，先用 `diag <关键词>` 查候选编码，选最贴切者。

### 第 2 步：查候选病组

对每个候选主诊断调 `group <编码>`，得到核心病组、综合病组及分值。核心病组未命中时输出带"综合(兜底)"标注的病组，方案中必须如实标注"兜底入组"。

### 第 3 步：生成多方案（默认 3 个，最多 5 个，按分值降序）

从三个维度组合生成方案，取分值最高的 3~5 个：

1. **换主诊断**：在事实边界内（见约束），把病历中已列的次要诊断提为主诊断，或对主诊断做编码层级微调，重新 `group` 查组。
2. **换/加操作**：同一诊断键下存在多个不同操作的病组（如腹腔镜胆囊切除 vs 胆囊穿刺引流），分别列出。
3. **保守治疗 vs 手术档位**：综合病组的保守治疗/诊断性操作/治疗性操作/手术各档位分值不同，均作为独立方案参与排序，标注"综合病组"。

需要寻找同族高分替代诊断时，调 `family <主诊断编码前3位>`，对比各 4 位键的最高分。

### 第 4 步：操作推荐

在方案列表之后，输出 2~3 条操作推荐，分两类标注：

- **贴合病情**：与病历中已有操作或病情最匹配的操作，可进入的病组及分值
- **分值更高**：若加做某操作可进入更高分值分组，给出该操作及对应病组、分值、费用

推荐的操作编码与名称必须能在 `group` 结果或 `operations.json` 中找到，不得推荐不存在的操作。

## 硬约束

1. **禁止引入病历中完全没有提及的诊断**——这是不可违反的底线。
2. 允许病历已列诊断的主次互换；允许同一诊断的编码层级微调（如"甲状腺乳头状癌"调整为上级编码"甲状腺恶性肿瘤"）。
3. 不允许的操作调整：推荐与病情明显无关、仅为冲高分值的操作。操作推荐必须与病情有合理关联。
4. 方案默认 3 个、最多 5 个，严格按分值降序。
5. 只输出 `group` 实际返回的病组；分值、费用照抄脚本输出，不得自行估算。

## 输出格式

纯文字逐行输出，**不用表格**。每个方案：

```
方案 1（推荐）
主诊断：C73 甲状腺恶性肿瘤
操作：06.4 甲状腺全切除术
入组编码：C73.x00-06.4001
病组名称：甲状腺恶性肿瘤-甲状腺全切除术
DIP 分值：95.00
职工付费标准：XXXX 元（分值 × 5.69）
居民付费标准：XXXX 元（分值 × 4.36）
调整说明：将主诊断从"甲状腺乳头状癌"调整为"甲状腺恶性肿瘤"上级编码

方案 2
...
```

说明：
- 无操作方案的操作行写"无（保守治疗）"，入组编码照抄综合病组编码（如 `K81-BSZL`）。
- 综合病组方案在调整说明或病组名称后标注"综合病组"；兜底命中标注"兜底入组"。
- 方案列表之后输出操作推荐段：

```
💡 操作推荐（贴合病情）：若行"颈部淋巴结活检术（40.11）"，可进入病组 AC29-3，
DIP 分值 110，职工付费标准 XXXX 元（×5.69），居民付费标准 XXXX 元（×4.36）。
💡 操作推荐（分值更高）：若加做"甲状腺全切除术（06.4）"，可进入病组 XX-1，
DIP 分值 XX，职工付费标准 XXXX 元，居民付费标准 XXXX 元。
```

用户只问 ICD 编码时，输出 Top 5 候选（`编码 名称`）即可，不展开分组推荐。
