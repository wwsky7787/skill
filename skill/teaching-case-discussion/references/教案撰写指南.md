## 1. 教案撰写的基本原则

### 1.1 科学性原则

- 内容符合医学科学的客观规律
- 所引用的医学知识准确无误
- 病例资料真实可靠
- 教学目标明确合理

### 1.2 规范性原则

- 教案格式符合本指南规定
- 项目齐全、格式统一
- 表述准确、术语规范
- 使用规范的医学术语和教育学术语

### 1.3 实用性原则

- 能够真正指导教学实践
- 具有可操作性和可执行性
- 时间分配合理
- 方法选择适当

### 1.4 创新性原则

- 根据具体病例特点灵活调整
- 根据教学对象情况个性化设计
- 融入最新的医学进展
- 体现先进的教学理念

### 1.5 以住院医师为中心

- 所有设计围绕促进住院医师自主学习能力
- 有效训练临床思维能力
- 预判住院医师可能提出的问题和困难
- 准备相应的引导策略和解决方案

## 2. 教案格式与结构

### 2.1 整体框架

```
一、基本信息
二、教学主题
三、教学病例资料
四、教学目标
五、讨论问题
六、课前准备
七、教学实施计划
八、评价与反馈计划
九、参考资料
```

### 2.2 篇幅要求

- 一般控制在 5000 至 10000 字
- 内容详实充分，避免冗长繁琐
- 重点突出，层次分明

### 2.3 标题层次

```
# 一级标题
## 二级标题
### 三级标题
```

## 3. 各部分撰写详解

### 3.1 基本信息

**必须包含的内容**：

| 项目 | 要求 |
|------|------|
| 培训基地名称 | 使用全称，与规培信息平台一致 |
| 专业基地/科室 | 准确反映专业领域 |
| 指导医师 | 姓名 + 职称（主任/副主任/主治医师） |
| 参加医师人数 | 8-15 人为宜 |
| 教学时长 | 60 分钟左右，精确到分钟 |
| 讨论日期 | 清晰标注 |

### 3.2 教学主题

**主题确定考虑因素**：

1. 符合规培各专业细则要求
2. 涵盖应掌握或熟悉的常见病、多发病
3. 在病因、发病机制、病理生理、临床表现、诊断、鉴别诊断、辅助检查和治疗等方面存在需要深入分析的问题
4. 具有一定的教学价值，能有效训练临床思维能力
5. 适当融入最新医学进展

**主题表述格式**：

- "疾病名称 + 讨论重点"
  - 例："肺炎链球菌肺炎的诊断与鉴别诊断——以一例社区获得性肺炎为例"
- "临床问题 + 诊疗要点"
  - 例："急性胸痛的临床思维训练"

### 3.3 教学病例资料

**病例选择标准**：

1. 以本专业培训细则中要求掌握或熟悉的常见病、多发病为主
2. 可适当选择具有教学价值的少见病或罕见病例
3. 病史清晰、体征明确、辅助检查资料完整、治疗过程规范

**病例摘要内容**：

- 患者基本信息（性别、年龄、职业等，隐去隐私）
- 主诉
- 现病史
- 既往史
- 个人史
- 家族史
- 体格检查结果
- 辅助检查结果
- 入院诊断
- 治疗经过
- 病情变化

**重要要点**：

- 包含阳性症状和体征
- 包含具有鉴别诊断意义的阴性症状和体征
- 病理诊断一般不列出（需要分型与制定治疗计划者除外）
- 辅助检查结果完整，适当配以必要的图像资料

**呈现方式**：

1. **一次性发放**：讨论前将完整病例资料一次性发放
2. **分步递呈**：按以下顺序逐步呈现
   - 第一步：主诉和现病史 → 引导提出初步诊断假设
   - 第二步：体格检查结果 → 引导验证或修正假设
   - 第三步：辅助检查结果 → 引导做出最终诊断并制定治疗计划

### 3.4 教学目标

**SMART 原则**：

| 原则 | 含义 | 示例 |
|------|------|------|
| S 具体 | 明确界定学习内容和预期结果 | "描述肺炎链球菌肺炎的典型临床表现" |
| M 可测量 | 可以通过评价方法检验 | "能够列出 3 个主要鉴别诊断" |
| A 可达成 | 符合实际水平，经过努力可实现 | 避免过于困难或简单 |
| R 相关 | 与规培要求紧密相关 | 体现核心能力培养 |
| T 有时限 | 在本次教学活动中达成 | 有明确时间节点 |

**行为动词使用**：

- **认知领域**：列出、描述、解释、比较、分析、评价、总结、制定、推荐
- **技能领域**：演示、应用、操作、实施、完成
- **情感领域**：认识、理解、认同、树立、培养

**目标层次**：

1. 知识记忆：列出、描述疾病概念、病因、临床表现
2. 知识理解：解释、阐述发病机制、诊断依据、治疗原则
3. 知识应用：运用知识分析病例，制定诊疗计划
4. 知识评价：评价诊疗方案优劣，提出独立见解

**示例**：

> 通过本病例讨论，住院医师能够：
> 1. 描述肺炎链球菌肺炎的典型临床表现和病理生理机制
> 2. 运用临床思维方法，对社区获得性肺炎做出正确的诊断和鉴别诊断
> 3. 根据最新指南，制定合理的抗感染治疗方案

### 3.5 讨论问题

**设计原则**：

1. 针对性和启发性
2. 开放性问题为主
3. 数量适度（2-3 个，最多 5 个）
4. 层层递进，逐步深入
5. 体现知识整合和横向联系

**示例**：

> 1. 该患者的临床表现支持肺炎链球菌肺炎的诊断吗？请列出支持点和不支持点
> 2. 需要与哪些疾病进行鉴别诊断？鉴别要点是什么？
> 3. 根据 CURB-65 评分，该患者的严重程度如何？应选择何种治疗方案？

### 3.6 课前准备

**指导医师准备**：

1. 选择合适的病种和教学病例
2. 明确讨论目标和讨论问题
3. 整理病例资料并确定呈现方式
4. 查阅文献和资料
5. 进行教学设计
6. 预设住院医师工作分工

**住院医师准备**：

1. 认真阅读发放的讨论资料（讨论前 3 天发放）
2. 查阅相关文献资料
3. 准备讨论发言提纲
4. 按安排承担指定任务

**指定任务示例**：

| 住院医师 | 任务内容 |
|----------|----------|
| 张医师 | 病历摘要汇报 |
| 李医师 | 解读实验室检查 |
| 王医师 | 解读影像学图像 |
| 赵医师 | 提出"反辩"思路 |

**场地与设备准备**：

- 场地布置（圆桌或 U 形布局）
- 影像资料播放设备测试
- 黑板/白板准备
- 教具准备
- 记录人员通知

### 3.7 教学实施计划

**时间分配框架**：

| 环节 | 时间 | 主要内容 |
|------|------|----------|
| 开场介绍 | 5-10 分钟 | 自我介绍、教学目标说明、宣布规则 |
| 病历摘要汇报 | 5-10 分钟 | 住院医师汇报 |
| 归纳病例特点 | 5-10 分钟 | 提炼关键信息 |
| 围绕问题讨论与分析 | 30-35 分钟 | 核心讨论 |
| 总结归纳 | 5-10 分钟 | 总结、评价、布置任务 |

**教学形式选择**：

1. **提问式教学**：通过问题引导思考
2. **讨论式教学**：鼓励发表不同观点
3. **反驳式教学**：培养批判性思维
4. **演示式教学**：运用黑板绘制思维导图
5. **案例式教学**：以病例为载体展开分析

**各环节要点**：

#### 开场介绍
- 营造积极学习氛围
- 明确讨论目标和规则
- 了解住院医师课前准备情况
- 询问是否有其他希望讨论的问题

#### 病历摘要汇报
- 由指定住院医师完成
- 简明扼要，重点突出
- 避免简单重复原始病历
- 指导医师点评

#### 归纳病例特点
- 总结应包含个人观点
- 注意条理性
- 包括病史、体征、辅助检查结果
- 有鉴别意义的阴性结果也应包含

#### 围绕问题讨论与分析（核心环节）
1. 从问题入手，围绕中心环节和临床问题
2. 综合运用各学科知识，展开横向教学
3. 鼓励评估诊治方案，认识"医患共同决策"
4. 指导辅助检查判读，提出独立见解
5. 指导做出正确诊断、鉴别诊断、诊疗计划
6. 结合病例讲解疑难问题
7. 适当介绍医学新进展
8. 合理教授专业英语词汇

#### 总结归纳
1. 对讨论案例的内涵和过程进行总结
2. 呼应教学目标
3. 评价住院医师是否达到预期目标
4. 点评参与度
5. 布置课后任务，引导延伸学习

### 3.8 评价与反馈计划

**对住院医师的评价**：

| 评价内容 | 评价方法 |
|----------|----------|
| 病例资料掌握程度 | 观察评价 |
| 问题分析能力 | 观察评价 |
| 临床思维展现 | 观察评价 |
| 专业知识运用 | 观察评价 |
| 团队合作与沟通 | 同行互评 |

**对课程的评价**：

| 评价内容 | 评价方法 |
|----------|----------|
| 病例选择恰当性 | 问卷调查 |
| 教学目标适合度 | 问卷调查 |
| 指导医师引导能力 | 问卷调查 |
| 总体收获 | 问卷调查 |

**课后作业形式**：

1. 撰写病例分析报告
2. 查阅指定文献并撰写阅读笔记
3. 开展延伸学习准备下次汇报
4. 临床实践应用并记录心得

### 3.9 参考资料

**资料类型**：

1. **经典教材**：《内科学》《外科学》《妇产科学》《儿科学》等
2. **临床指南**：中华医学会、各专业学会发布的指南和专家共识
3. **重要文献**：高影响因子期刊发表的研究论文、综述
4. **在线资源**：专业网站、数据库、学习平台

**选择原则**：

- 权威性：优先选择权威教材、官方指南
- 系统性：涵盖主要知识点
- 前沿性：纳入最新研究进展
- 层次性：不同难度层次，满足不同程度需求

## 4. 常见问题与解答

### Q1: 教学目标应该设置几个？

**A**: 一般设置 2-3 个，最多不超过 5 个。目标过多会导致重点不突出，难以在有限时间内全部达成。

### Q2: 讨论问题应该如何设计？

**A**: 问题应具有针对性和启发性，以开放性问题为主，避免简单的是非判断题。问题数量 2-3 个为宜，最多不超过 5 个。

### Q3: 病例资料应该一次性发放还是分步递呈？

**A**: 两种方式各有优势。一次性发放便于住院医师全面了解病例；分步递呈适用于以临床思维训练为主的教学，可引导住院医师逐步完成诊断推理。

### Q4: 如何将前沿知识融入教案？

**A**: 可在以下环节融入：
- 讨论问题中设置与新进展相关的内容
- 病例分析中介绍最新诊疗方案
- 总结中适当介绍医学新进展
- 参考资料中列出最新文献和指南

### Q5: 如何避免教学病例讨论变成"独角戏"？

**A**: 
- 采用以住院医师为主体的互动式教学
- 多采用提问式、讨论式、反驳式教学
- 鼓励住院医师发表独立见解
- 指导医师适时引导和点评，而非全程讲授

### Q6: 教案篇幅应该多长？

**A**: 一般控制在 3000-5000 字为宜。既要内容详实充分，又要避免冗长繁琐。
