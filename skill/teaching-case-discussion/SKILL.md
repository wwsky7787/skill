# 教学病例讨论教案撰写

本技能协助住院医师规范化培训指导医师撰写规范、高质量的教学病例讨论教案。

## 工具使用

### 网络搜索（web_fetch）

在设计讨论问题的参考答案时，应使用 `web_fetch` 工具搜索权威医学资源：

- **指南/共识**：中华医学会官网、各专科分会指南
- **专业网站**：UpToDate、医脉通、丁香园
- **学术数据库**：CNKI、万方、PubMed

**搜索示例**：
```
web_fetch:
  url: "https://www.cma.org.cn/指南名称"
  prompt: "提取该指南关于疾病诊断要点和治疗原则的核心内容"
```

## 核心工作流程

### 1. 收集基本信息

**默认基本信息**（如用户未提供，则使用以下默认值）：

- **培训基地名称**：十堰市人民医院普外科基地
- **专业基地/科室名称**：甲乳血管外科一病区
- **指导医师姓名及职称**：王巍（主治医师）
- **参加讨论的住院医师人数**：在科住培医师和基地住培医师
- **教学时长**：60 分钟

**需向用户询问的信息**：

- **教学病例资料**（主诉、现病史、体格检查、辅助检查、诊断、治疗经过等）
- **讨论日期**（可选，默认为当前日期）

如用户提供的信息与默认值不同，以用户提供的为准。

### 2. 确定教学主题

根据病例特点，帮助用户确定明确的教学主题。主题格式建议：
- "疾病名称 + 讨论重点"，如："肺炎链球菌肺炎的诊断与鉴别诊断——以一例社区获得性肺炎为例"
- "临床问题 + 诊疗要点"，如："急性胸痛的临床思维训练"

### 3. 设计教学目标

协助用户设计 2-3 个教学目标（最多不超过 5 个），目标应：
- 以问题形式呈现
- 遵循 SMART 原则
- 使用规范的行为动词（列出、描述、解释、分析、评价、制定等）
- 体现重点知识和前沿知识

**目标层次参考**：
- 知识记忆：列出、描述疾病概念、病因、临床表现
- 知识理解：解释、阐述发病机制、诊断依据、治疗原则
- 知识应用：运用知识分析病例，制定诊疗计划
- 知识评价：评价诊疗方案优劣，提出独立见解

### 4. 设计讨论问题

设计 2-3 个核心讨论问题（最多不超过 5 个），问题应：
- 具有针对性和启发性
- 以开放性问题为主
- 层层递进，逐步深入
- 体现知识整合和横向联系

**参考答案要求**：
- 每个讨论问题后需附上**简要参考答案**
- 参考答案应基于最新临床指南、专家共识或高质量文献
- 使用 `web_fetch` 等工具搜索网络资源获取权威信息
- 参考答案应简洁明了，涵盖关键诊断要点、治疗原则或争议点
- 答案长度控制在 100-300 字/题，避免冗长

**示例格式**：
```
讨论问题 1：该患者外伤后出现腹部、会阴部疼痛伴重度贫血，如何快速判断出血部位和出血原因？

参考答案：
快速判断出血部位和原因需结合：①病史特点（外伤机制、时间、症状演变）；②体格检查（瘀斑范围、肿块位置、压痛部位）；③实验室检查（血红蛋白动态监测）；④影像学检查（CTA 是首选，可明确活动性出血部位和血肿范围）。腹壁动脉破裂出血的典型表现为外伤后进行性加重的贫血伴局部血肿，CTA 可见造影剂外溢征象。
```

### 5. 制定教学实施计划

按照以下时间框架制定详细计划：

| 环节 | 时间 | 主要内容 |
|------|------|----------|
| 开场介绍 | 5-10 分钟 | 自我介绍、教学目标说明、宣布讨论规则 |
| 病历摘要汇报 | 5-10 分钟 | 住院医师汇报病例摘要 |
| 归纳病例特点 | 5-10 分钟 | 提炼病例关键信息 |
| 围绕问题讨论与分析 | 30-35 分钟 | 核心讨论环节 |
| 总结归纳 | 5-10 分钟 | 总结要点、评价反馈、布置课后任务 |

### 6. 设计评价与反馈计划

包括：
- 对住院医师的评价（课前准备、参与度、临床思维能力等）
- 对课程的评价（病例选择、教学方法、互动效果等）
- 课后作业布置（病例分析报告、文献查阅等）

### 7. 列出参考资料

推荐以下类型的参考资料：
- 经典教材（《内科学》《外科学》等）
- 临床指南（中华医学会指南、专家共识）
- 重要文献（高质量研究论文、综述）
- 在线资源（专业网站、数据库）

## 教案质量标准

撰写时严格遵循以下标准：

### 基本原则
- **科学性**：内容符合医学规律，知识准确，病例真实
- **规范性**：格式统一，项目齐全，表述准确
- **实用性**：可操作，可执行，能指导教学实践
- **创新性**：融入最新进展，体现先进教学理念

### 关键要求
- 病例选择：常见病、多发病为主，病史清晰，资料完整
- 病例资料：包含阳性和阴性体征，病理诊断一般不列出
- 以住院医师为中心，促进自主学习和临床思维训练
- 适当融入前沿知识（新指南、新药物、新技术、新进展）
- **字数控制**：教案文字总量控制在**500-10000 字**之间
  - 基本信息、教学主题、病例摘要：约 300-500 字
  - 教学目标、讨论问题（含参考答案）：约 300-800 字
  - 课前准备、教学实施计划：约 200-400 字
  - 评价与反馈、参考资料：约 100-300 字
  - 根据病例复杂程度适当调整，确保内容精炼、重点突出

- 指导医师：

## 二、教学主题
- 主题名称：

## 三、教学病例资料
- 病例摘要（基本信息、主诉、现病史、既往史、体格检查、辅助检查、诊断、治疗经过）

## 四、教学目标
1. ...

## 五、讨论问题

   **参考答案**：...

   **参考答案**：...

### DOCX 格式（符合公文规范）

调用 `scripts/generate_teaching_plan.py` 生成，格式要求：

**页面设置**：
- A4 纸（210mm × 297mm）
- 版心尺寸：156mm × 225mm
- 页边距：上 36mm、下 36mm、左 27mm、右 27mm（不含页码）
- 每页 22 行，每行 28 字

**字体字号**：
- 正文：三号仿宋_GB2312，行间距 28 磅
- 一级标题（"一、"）：三号黑体，句尾无标点
- 二级标题（"(一)"）：三号楷体，句尾可有可无标点
- 三级标题（"1."）：三号仿宋，有标点
- 四级标题（"(1)"）：三号仿宋，必须有标点

**文字颜色**：
- 正文文字为黑色
- 标题醒目、美观、庄重

**单位姓名**：
- 标题下空一行写明单位和姓名（楷体 GB_2312）

## 使用示例

**用户输入**：
"我需要一个关于社区获得性肺炎的教学病例讨论教案，患者男，65 岁，发热、咳嗽 5 天..."

**你的响应**：
1. 确认已收集的信息是否完整
2. 如信息不足，追问缺失的病例资料
3. 根据完整信息生成规范教案
4. 提供教案质量改进建议
5. 询问是否需要生成 DOCX 格式文件

## DOCX 文件生成

当用户需要生成 DOCX 格式教案时：

1. 收集完整的教案数据（基本信息、病例资料、教学目标等）
2. 调用 `scripts/generate_teaching_plan.py` 脚本
3. 将教案数据作为参数传递给 `generate_teaching_plan 教案 ()` 函数
4. 输出 DOCX 文件路径给用户

**示例代码**：

```python
from scripts.generate_teaching_plan import generate_teaching_plan 教案

教案_data = {
    '基本信息': {
        '培训基地': 'XX 医院',
        '专业基地/科室': '内科基地/呼吸内科',
        '指导医师': '张三 主任医师',
        '参加医师人数': '10 人',
        '教学时长': '60 分钟',
        '讨论日期': '2026 年 3 月 5 日'
    },
    '教学主题': {...},
    '教学病例资料': {...},
    '教学目标': [...],
    '讨论问题': [...],
    ...
}

generate_teaching_plan 教案 (教案_data, '输出路径/教案.docx')
```

## 注意事项

1. **患者隐私保护**：隐去患者姓名、身份证号等隐私信息
2. **时间协调**：建议讨论前 3 天发放病例资料给住院医师
3. **互动式教学**：避免变成"独角戏"，采用提问式、讨论式、反驳式教学
4. **持续改进**：每次讨论后总结反思，优化教案
