# 湖北2.0版 ICD 编码与手术智能查询技能

本技能用于接收临床医生的自然语言描述，并在本地标准湖北2.0版ICD库（约5万条疾病与手术记录）中执行毫秒级精确检索与标准化输出。

## 执行规范与工作流

### 第一步：输入合规性与意图判定（拦截与分流）

1. **混合输入拦截原则（严格执行）**：
   - 若用户输入**同时包含明确的疾病诊断与手术操作**（例如：“帮我查一下高血压和阑尾切除术”、“诊断胃癌行根治性切除”、“乳腺结节 微创”意图未明），**必须坚决拒绝查询**。
   - 拒绝并提示固定格式：
     > “拒绝查询：检测到您的输入同时包含疾病与手术（或意图不明确），请明确本次是查询【疾病诊断】还是【手术操作】，或分开发送查询。”
   - *注：若疾病名称仅作为手术术式的修饰语（例如“左乳腺癌改良根治术”、“胆囊结石切除术”、“腹股沟斜疝无张力修补术”），核心意图属于手术，应按手术正常查询，不予拦截。*

2. **意图路由**：
   - **手术操作（Surgery）**：包含“术、切除、结扎、修补、引流、穿刺、置管、吻合、镜、消融、旋切、剥脱、造瘘、清扫、成形”等动作。
   - **疾病诊断（Disease）**：包含“病、炎、症、综合征、癌、瘤、坏死、梗死、损伤、骨折、结石、感染、狭窄”等临床病态。

---

### 第二步：执行底层工具检索

利用技能根目录下的自包含 Python 检索脚本执行秒级查询（纯标准库，跨平台兼容）：

```bash
# 查询手术（输出 Top 5 候选）
python scripts/query.py -t surgery "<查询词/标准化提取词>" -n 5

# 查询疾病（输出 Top 5 候选）
python scripts/query.py -t disease "<查询词/标准化提取词>" -n 5

# 仅在需要机器结构化解析时使用 --json
python scripts/query.py -t surgery "<查询词>" --json
```

**智能检索策略**：
- **语义桥接**：若用户的自然语言与标准库差异较大（如“大三阳”、“微创切阑尾”），大模型应先根据医学常识提取出标准医学名词（如“慢性乙型肝炎”、“腹腔镜下阑尾切除术”），再调用脚本检索。
- **编码直查**：若用户直接输入了类似 `40.3x00x001` 或 `I10.x00x002` 的编码，脚本会自动命中唯一记录。

---

### 第三步：格式化输出合同

1. **唯一/确定命中时**（用户输入非常精准，或库中只有唯一样本）：
   - **疾病输出格式**：
     `疾病名称（疾病编码）`
     *例如：* `高血压（I10.x00x002）`
   - **手术输出格式**（必须带手术级别）：
     `手术名称（手术编码） [X级]`
     *例如：* `淋巴结扩大性区域性切除术（40.3x00x001） [3级]`

2. **存在多种可能或拿不准时**（列出至少 5 项，按关联程度由高到低排列）：
   - 示例：
     ```text
     1. 单侧乳腺改良根治术（85.4301） [3级]
     2. 双侧乳腺改良根治术（85.4401） [3级]
     3. 单侧保乳乳腺改良根治术（85.4302） [3级]
     4. 双侧保乳乳腺改良根治术（85.4402） [3级]
     5. 腔镜下单侧乳房改良根治术（85.4300x004） [3级]
     ```

3. **零幻觉红线**：
   - 严禁臆造、篡改任何 ICD 编码与手术级别。所有输出的编码和名称必须 100% 来源于 `scripts/query.py` 查库返回的真实内容。

## 目录与跨平台部署说明

本技能完全自包含在技能文件夹中：
- `SKILL.md`：本技能定义文件
- `icd_hubei2.db`：高压缩、毫秒级检索的湖北2.0全量SQLite数据库（疾病35,725条 + 手术13,664条）
- `scripts/query.py`：零第三方依赖检索引擎（支持 Windows、Ubuntu/Debian、macOS，仅需 Python 3.8+）
- `scripts/build_db.py`：源 Excel 到 SQLite 的数据抽取与压缩构建脚本
