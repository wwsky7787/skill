# 教学查房教案质量检查清单

本检查清单用于评估教学查房教案的质量，确保教案符合《住院医师规范化培训教学查房指南（2021 年版）》的要求。

## 一、基本信息（10 分）

### (一) 教案标识
- [ ] 教学查房标题明确（疾病名称 + 教学查房）
- [ ] 专业基地和科室填写完整
- [ ] 指导医师信息完整（姓名、职称）
- [ ] 教学日期明确
- [ ] 参与住院医师信息完整
- [ ] 教学时长合理（60-90 分钟）

### (二) 格式规范
- [ ] 纸张设置：A4（210mm × 297mm）
- [ ] 页边距：上 36mm、下 36mm、左 27mm、右 27mm
- [ ] 字体：正文三号仿宋_GB2312
- [ ] 行间距：固定值 28 磅
- [ ] 标题层级正确（一、→ (一) → 1. → (1)）

**评分标准：**
- 优秀（9-10 分）：所有项目完整，格式完全规范
- 良好（7-8 分）：基本项目完整，格式基本规范
- 合格（6 分）：主要项目完整，格式有小错误
- 不合格（0-5 分）：关键信息缺失或格式错误多

## 二、教学目标（15 分）

### (一) 目标维度
- [ ] 包含知识目标
- [ ] 包含能力目标
- [ ] 包含素养目标
- [ ] 三维目标比例合理

### (二) SMART 原则
- [ ] 目标具体（Specific）
- [ ] 目标可测量（Measurable）
- [ ] 目标可达成（Achievable）
- [ ] 目标相关（Relevant）
- [ ] 目标有时限（Time-bound）

### (三) 目标层次
- [ ] 使用恰当的行为动词（掌握、熟悉、了解）
- [ ] 目标数量适当（每个维度 2-4 条）
- [ ] 目标层次分明（记忆、理解、应用、评价）

**评分标准：**
- 优秀（13-15 分）：三维目标完整，符合 SMART 原则，层次清晰
- 良好（10-12 分）：三维目标基本完整，基本符合 SMART 原则
- 合格（8-9 分）：有三维目标，但部分目标表述不够具体
- 不合格（0-7 分）：目标缺失或表述模糊

## 三、病例摘要（15 分）

### (一) 病例选择
- [ ] 病例具有典型性和代表性
- [ ] 符合培训细则要求（常见病、多发病）
- [ ] 具有教学价值和讨论空间
- [ ] 病史清晰、资料完整

### (二) 内容完整
- [ ] 患者基本信息（性别、年龄等）
- [ ] 主诉（20 字以内，反映核心问题）
- [ ] 现病史（按时间顺序，包含诊治经过）
- [ ] 既往史（相关疾病、过敏史等）
- [ ] 个人史（生活习惯、职业等）
- [ ] 家族史（遗传性疾病等）
- [ ] 体格检查（阳性体征和重要阴性体征）
- [ ] 辅助检查（关键异常结果）
- [ ] 初步诊断（按主次顺序）
- [ ] 诊疗经过（主要措施和疗效）

### (三) 隐私保护
- [ ] 使用化名保护患者隐私
- [ ] 隐去敏感个人信息
- [ ] 符合医学伦理要求

**评分标准：**
- 优秀（13-15 分）：病例典型，资料完整，隐私保护得当
- 良好（10-12 分）：病例较典型，资料较完整
- 合格（8-9 分）：病例基本符合要求，资料基本完整
- 不合格（0-7 分）：病例选择不当或资料严重缺失

## 四、教学流程与时间安排（15 分）

### (一) 查房准备阶段（示教室）
- [ ] 时间分配合理（5-10 分钟）
- [ ] 包含成员介绍
- [ ] 介绍教学目标
- [ ] 宣布流程和注意事项

### (二) 临床信息采集阶段（床旁）
- [ ] 时间分配合理（15-20 分钟）
- [ ] 住院医师汇报病史（5-6 分钟）
- [ ] 指导医师核实病史并示范
- [ ] 住院医师体格检查操作
- [ ] 指导医师示范医患沟通

### (三) 病例讨论阶段（示教室）
- [ ] 时间分配合理（40-60 分钟）
- [ ] 总结床旁查房
- [ ] 归纳病例特点
- [ ] 讨论诊断与鉴别诊断
- [ ] 分析辅助检查结果
- [ ] 讨论诊疗方案
- [ ] 介绍最新进展
- [ ] 教学总结

### (四) 时间分配表
- [ ] 包含时间安排表格
- [ ] 表格内容完整（阶段、时间、内容、参与者、指导医师职责）
- [ ] 总时间控制在 60-90 分钟

**评分标准：**
- 优秀（13-15 分）：流程完整，时间分配合理，符合"三部曲"模式
- 良好（10-12 分）：流程较完整，时间分配较合理
- 合格（8-9 分）：基本流程具备，时间分配基本合理
- 不合格（0-7 分）：流程混乱或时间分配严重不合理

## 五、教学重点与难点（10 分）

### (一) 教学重点
- [ ] 重点明确（2-4 条）
- [ ] 紧扣教学目标
- [ ] 体现疾病诊疗核心要点
- [ ] 是住院医师必须掌握的内容

### (二) 教学难点
- [ ] 难点明确（2-4 条）
- [ ] 分析住院医师理解困难点
- [ ] 包含复杂机制或鉴别思路
- [ ] 包含特殊情况处理

### (三) 重点难点区分
- [ ] 重点和难点有明确区分
- [ ] 重点和难点有对应关系
- [ ] 针对难点有突破策略

**评分标准：**
- 优秀（9-10 分）：重点难点明确，分析准确，有突破策略
- 良好（7-8 分）：重点难点较明确，分析较准确
- 合格（6 分）：有重点难点，但区分不够清晰
- 不合格（0-5 分）：重点难点缺失或分析错误

## 六、讨论问题设计（15 分）

### (一) 问题层次
- [ ] 包含事实性问题（2-3 个）
- [ ] 包含分析性问题（2-3 个）
- [ ] 包含评价性问题（2-3 个）
- [ ] 问题层次递进，由浅入深

### (二) 问题质量
- [ ] 问题具有针对性
- [ ] 问题具有启发性
- [ ] 问题具有开放性（无唯一标准答案）
- [ ] 问题与病例紧密结合

### (三) 参考答案
- [ ] 提供参考答案
- [ ] 答案准确、完整
- [ ] 答案有循证依据
- [ ] 答案包含分析过程

**评分标准：**
- 优秀（13-15 分）：三层次问题完整，质量高，答案详实
- 良好（10-12 分）：三层次问题较完整，质量较好
- 合格（8-9 分）：有问题设计，但层次不够清晰
- 不合格（0-7 分）：问题缺失或质量差

## 七、自学任务与参考文献（10 分）

### (一) 自学任务
- [ ] 任务明确具体（2-4 项）
- [ ] 与教学目标相呼应
- [ ] 任务可执行、可评价
- [ ] 包含文献阅读、思考题等

### (二) 参考文献
- [ ] 包含指南与共识
- [ ] 包含重要文献
- [ ] 包含教材专著
- [ ] 文献数量适当（5-10 篇）

### (三) 文献质量
- [ ] 文献权威（核心期刊、权威机构）
- [ ] 文献时效（近 3-5 年）
- [ ] 文献格式规范
- [ ] 包含最新指南（近 2 年）

**评分标准：**
- 优秀（9-10 分）：自学任务明确，参考文献权威、新颖
- 良好（7-8 分）：自学任务较明确，参考文献较权威
- 合格（6 分）：有自学任务和参考文献，但质量一般
- 不合格（0-5 分）：自学任务缺失或参考文献陈旧

## 八、教学反思与评价（5 分）

### (一) 评价内容
- [ ] 包含教学目标达成情况评价
- [ ] 包含主要经验与不足
- [ ] 包含改进措施

### (二) 评价方式
- [ ] 有住院医师评价计划
- [ ] 有课程评价计划
- [ ] 评价方法具体可行

### (三) 反思框架
- [ ] 预留反思空间（教学后填写）
- [ ] 反思内容全面
- [ ] 改进措施具体

**评分标准：**
- 优秀（5 分）：评价内容完整，方法具体，反思框架清晰
- 良好（4 分）：评价内容较完整，方法较具体
- 合格（3 分）：有评价内容，但不够具体
- 不合格（0-2 分）：评价内容缺失

## 九、前沿知识体现（5 分）

### (一) 指南更新
- [ ] 引用最新指南（近 2 年）
- [ ] 对比新旧指南差异
- [ ] 解读指南更新要点

### (二) 研究进展
- [ ] 介绍相关领域新进展
- [ ] 引用高质量研究
- [ ] 说明临床意义

### (三) 循证医学
- [ ] 体现循证医学理念
- [ ] 引用循证证据
- [ ] 培养住院医师循证思维

**评分标准：**
- 优秀（5 分）：前沿知识充实，指南新颖，循证依据充分
- 良好（4 分）：有前沿知识，指南较新
- 合格（3 分）：有前沿知识提及，但不够深入
- 不合格（0-2 分）：无前沿知识或知识陈旧

## 十、总体评价（5 分）

### (一) 字数要求
- [ ] 总字数在 8000-12000 字

### (二) 逻辑结构
- [ ] 结构完整，层次清晰
- [ ] 各部分逻辑连贯
- [ ] 内容相互呼应

### (三) 语言表达
- [ ] 语言简洁精炼
- [ ] 医学术语准确
- [ ] 无错别字和语病

**评分标准：**
- 优秀（5 分）：字数符合，结构严谨，表达流畅
- 良好（4 分）：字数基本符合，结构较严谨
- 合格（3 分）：字数偏差较大或结构有小问题
- 不合格（0-2 分）：字数严重不符或结构混乱

## 使用说明

1. **自查**：指导医师完成教案后对照清单逐项检查
2. **同行评议**：邀请同行教师使用清单进行评议
3. **专家审核**：专业基地组织专家使用清单进行审核
4. **持续改进**：根据评分结果和改进建议完善教案
