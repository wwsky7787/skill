# 网络搜索参考指南

本文件提供教学查房教案生成过程中进行网络搜索的指导，帮助补充讨论问题和最新研究进展。

## 一、搜索目的

### (一) 补充讨论问题
1. 获取疾病的典型临床表现和诊断要点
2. 了解鉴别诊断的关键点
3. 掌握治疗方案的最新推荐
4. 发现临床实践中的常见问题和误区

### (二) 获取最新研究
1. 最新临床指南和专家共识
2. 重要临床试验结果
3. 诊疗技术的新进展
4. 药物治疗的新证据

### (三) 完善参考文献
1. 指南与共识
2. 高质量研究论文
3. 系统评价和 Meta 分析
4. 权威教材和专著

## 二、推荐搜索资源

### (一) 中文资源
1. **中华医学会官网**（www.cma.org.cn）
   - 各专业分会发布的临床指南
   - 专家共识
   - 诊疗规范

2. **中国知网 CNKI**（www.cnki.net）
   - 中文核心期刊论文
   - 学位论文
   - 会议论文

3. **万方数据**（www.wanfangdata.com.cn）
   - 医学期刊论文
   - 指南共识
   - 临床病例讨论

4. **维普网**（www.cqvip.com）
   - 中文科技期刊
   - 医学专业文献

5. **丁香园**（www.dxy.cn）
   - 临床用药指南
   - 医学论坛讨论
   - 循证医学资源

### (二) 英文资源
1. **PubMed**（pubmed.ncbi.nlm.nih.gov）
   - 生物医学文献数据库
   - 免费检索
   - 链接全文

2. **UpToDate**（www.uptodate.com）
   - 循证医学临床资源
   - 专题综述
   - 患者教育资料

3. **BMJ Best Practice**（bestpractice.bmj.com）
   - 循证临床决策支持
   - 诊断和治疗流程
   - 最新研究证据

4. **Cochrane Library**（www.cochranelibrary.com）
   - 系统评价
   - Meta 分析
   - 临床对照试验

5. **各专业学会官网**
   - 美国医学会（AMA）
   - 欧洲相关学会
   - 国际专业组织

## 三、搜索策略

### (一) 搜索关键词构建

**基本格式：**
```
[疾病名称] + [搜索主题] + [文献类型] + [时间]
```

**示例：**
- "社区获得性肺炎 诊断 指南 2024"
- "肺炎链球菌 耐药 治疗 进展 综述"
- "CAP 抗感染治疗 最新研究"

### (二) 搜索主题分类

**1. 诊断相关**
- 诊断标准
- 诊断流程
- 鉴别诊断
- 辅助检查

**2. 治疗相关**
- 治疗原则
- 药物治疗
- 非药物治疗
- 治疗方案

**3. 预后相关**
- 预后评估
- 随访管理
- 并发症预防

**4. 指南共识**
- 临床实践指南
- 专家共识
- 诊疗规范

### (三) 高级搜索技巧

**1. 限定时间范围**
- PubMed：在搜索框使用"2020:2024[dp]"
- CNKI：使用时间筛选功能

**2. 限定文献类型**
- PubMed：使用过滤器（Guideline, Review, Meta-Analysis）
- CNKI：选择文献类型（期刊、学位论文等）

**3. 限定人群**
- PubMed：使用 MeSH 词或过滤器（Adult, Aged, etc.）

**4. 限定语言**
- 根据需要选择中文或英文文献

## 四、搜索流程

### (一) 确定搜索需求
1. 明确疾病名称和主要临床问题
2. 确定需要补充的内容类型（讨论问题、研究进展、参考文献）
3. 设定搜索的优先级

### (二) 选择搜索资源
1. 指南共识：优先选择中华医学会官网、各专业学会官网
2. 研究论文：优先选择 PubMed、CNKI
3. 循证资源：优先选择 UpToDate、BMJ Best Practice

### (三) 执行搜索
1. 构建搜索关键词
2. 应用适当的筛选条件
3. 浏览搜索结果

### (四) 筛选文献
1. 阅读标题和摘要
2. 评估文献质量
3. 选择最相关的文献

### (五) 提取信息
1. 记录关键信息
2. 整理讨论问题
3. 归纳研究进展
4. 格式化参考文献

## 六、参考文献格式

### (一) 期刊论文
```
作者。文章标题。期刊名，年，卷 (期): 起止页码
```

**示例：**
```
中华医学会呼吸病学分会。社区获得性肺炎诊断和治疗指南（2023 版）.中华结核和呼吸杂志，2023, 46(12): 1-24
```

### (二) 指南共识
```
发布机构。指南名称。期刊名，年，卷 (期): 起止页码
```

**示例：**
```
Metlay JP, Waterer GW, Long AC, et al. Diagnosis and Treatment of Adults with Community-acquired Pneumonia. An Official Clinical Practice Guideline of the American Thoracic Society and Infectious Diseases Society of America. Am J Respir Crit Care Med, 2019, 200(7): e45-e67
```

### (三) 专著
```
作者。书名。版次。出版地：出版社，年份
```

**示例：**
```
王辰。呼吸病学。第 3 版。北京：人民卫生出版社，2022
```

## 七、质量评估

### (一) 文献质量评估
1. **来源可靠性**：是否来自权威期刊或机构
2. **时效性**：是否为近 3-5 年文献
3. **证据级别**：是否为高质量研究（RCT、Meta 分析等）
4. **适用性**：是否适用于中国临床实践

### (二) 信息准确性验证
1. 交叉验证多个来源
2. 优先选择指南和共识
3. 注意研究的局限性
4. 考虑临床实际情况
